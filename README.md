# Estudos de Python

Organização do meu aprendizado de programação em Python.

## Fonte principal

- **Livro:** [Introdução à Programação com Python](https://python.nilo.pro.br/), de Nilo Ney Coutinho Menezes (4ª edição, Novatec).

## Estrutura

```
.
├── 2 - Início/                → capítulo 2
│   ├── exemplos/              → listagens do livro
│   └── exercicios/            → minhas resoluções
├── 3 - Variáveis/             → capítulo 3
├── 4 - Condições/             → capítulo 4
├── 5 - Repetições/            → capítulo 5
├── 6 - Listas e dicionários/  → capítulo 6
└── extras/                    → material de outras fontes de estudo
```

Cada pasta numerada corresponde a um capítulo do livro. Dentro dela:
- **`exemplos/`** — programas/lista das listagens do capítulo.
- **`exercicios/`** — minhas soluções para os exercícios do capítulo.

A pasta **`extras/`** guarda anotações e programas de outras fontes (vídeos, cursos, testes), que não seguem a numeração do livro.

## Regra de nomeação

- Arquivos do livro: `Exemplo X.Y.py` e `Exercício X.Y.py`
  - `X` = capítulo, `Y` = número no livro.
- Material de outras fontes: colocar em `extras/` com nome descritivo.
